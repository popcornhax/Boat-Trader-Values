# Boat Trader Values

Safari Web Extension that opens Boat Trader's price checker in an overlay on the current listing page, fills the form from the listing details, and submits it.

## Local Build

1. Open `Boat Trader Values.xcodeproj`.
2. Build and run the macOS app target.
3. In Safari, enable the extension in Settings > Extensions.
4. On a Boat Trader listing, click the toolbar button.

The portable WebExtension source lives in `extension/`.
